# v0.1 Prototype Plan

## Target

Build a Discord-first editable status message prototype without changing the original `openclaw-status-update-plugin`.

## Minimal behavior

1. First `status_update` call sends a message.
2. Store returned message id in session/task-scoped memory.
3. Later `status_update` calls try to edit that message.
4. If edit fails, send a new message and replace cached message id.
5. Apply throttle and dedupe.
6. If channel does not support edit, fallback to send.

## Proposed config

```json
{
  "mode": "auto",
  "prefix": "狀態更新：",
  "maxLength": 240,
  "silent": true,
  "minUpdateIntervalMs": 5000,
  "dedupe": true
}
```
