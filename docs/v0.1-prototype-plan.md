# v0.1 Prototype Plan

## Target

Build a Discord-first one-shot UI wrapper for status updates without changing the original `openclaw-status-update-plugin`.

## Minimal behavior

1. Receive `status_update_ui({ message })`.
2. Normalize and clamp the message.
3. Build a small UI card using OpenClaw semantic presentation when available.
4. Fallback to a clean Markdown text card if rich UI fails or is unsupported.
5. Send one new message.
6. Do not edit previous messages.
7. Do not store message ids.

## Proposed config

```json
{
  "title": "OpenClaw 正在處理",
  "prefix": "狀態更新：",
  "maxLength": 240,
  "silent": true,
  "style": "presentation"
}
```

## Deferred

- editable message mode
- persistent task state
- progress bar
- checklist rendering
- full task cards
